划词就译，截屏也译。
翻译引擎由你定。

随译是 Windows 上的桌面翻译助手：在任何应用里选中文字按 Alt+D 出译文， 框选屏幕按 Alt+S 识别并翻译， 输入框里写完中文按 Alt+T 直接换成目标语言。 翻译服务可以是 DeepSeek、智谱、Kimi、Ollama 或任何 OpenAI 兼容的端点，多个服务同时出结果做对比。

能做什么

多服务并发对比

把几个 AI 服务都配上，一次翻译同时出几份译文，哪家更准一眼看得出来。服务可启停、可排序。

划词翻译

任意应用里选中文字按 Alt+D，弹窗出现在光标旁边，流式出稿，失焦自动隐藏，也可以钉住。

截图识别

Alt+S 冻结鼠标所在的那块屏幕，框选后离线 OCR 识别。识别在本机完成，截图不上传。

输入框转译

Alt+T 把当前输入框的中文整体换成目标语言。切换窗口时会自动放弃写回，改成复制到剪贴板。

词典、朗读与历史

单词可出音标与义项；本地语音离线朗读；翻译历史可搜索、按来源筛选，失败记录也会留下。

插件系统

放一个目录就能加插件，支持翻译、OCR、语音、动作四类扩展点，跑在 QuickJS 沙箱里。

安装与首次使用

Windows SmartScreen 提示：安装包没有购买代码签名证书，首次运行会提示「Windows 已保护你的电脑」。 点「更多信息」→「仍要运行」即可。如果介意，可以先在 仓库里核对源码，再自行构建。
  • 系统要求：Windows 10 1809 及以上，x64。Windows 11 自带 WebView2；Windows 10 若提示缺失，装一次 WebView2 运行时即可。
  • 装好后打开「设置 → 服务配置」，点「添加服务」，协议选 OpenAI 兼容，填 Base URL、API Key 和模型名；DeepSeek、智谱、Kimi、Ollama、OneAPI 中转都适用。
  • 填完点一下「测试连接」，它会告诉你 Key 是否有效、网关是否可达、模型是否在权限范围内。
  • API Key 只写进 Windows 凭据管理器，配置文件里零明文。

快捷键

动作快捷键说明
划词翻译Alt + D取选中文字，在光标处弹出翻译窗
截图识别Alt + S冻结鼠标所在显示器，框选后离线识别
输入框转译Alt + T翻译当前输入框内容并原位写回
关闭弹窗Esc隐藏当前弹窗，内容保留

从源码构建

需要 Node 18+、pnpm、Rust stable（MSVC 工具链）。 

pnpm install
pnpm tauri dev      # 开发调试
pnpm tauri build    # 打包安装程序

仓库里的 .github/workflows/release.yml 会在打 tag 时自动完成构建与发布。
