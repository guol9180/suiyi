两个入口

默认是这两个，都能在设置 → 热键里改。浏览器里建议把划词换成 Ctrl+Alt+D，Alt+D 会先被地址栏抢走。

Alt+D

划词翻译

在任意应用里选中文字，译文窗口出现在光标附近并流式出稿。窗口失焦自动隐藏，也可以钉住留在屏幕上。

Alt+S

截图识别

所有显示器一起冻结，在任意一块屏起框、跨屏拖选；文字在本机识别，图片不上传。没框到文字时有重试出口。

×

托盘常驻

点 × 时问一次「直接关闭 / 收进托盘」，可以记住选择。收进托盘后热键继续可用，单击右下角图标就能叫回窗口。

界面

下面的窗口不是截图，是和界面同步维护的代码复刻——应用更新，这里跟着更新。

安装

安装包没有代码签名。首次运行时 Windows 会提示「已保护你的电脑」， 点「更多信息」再点「仍要运行」即可。介意的话可以 对着源码自己构建。

装好并启动

Windows 11 自带 WebView2；Windows 10 若提示缺失，装一次 WebView2 运行时。

配一个翻译服务

设置 → 服务配置 → 添加服务。选内置提供商会自动填好地址、协议与推荐模型， DeepSeek、智谱、Kimi、Ollama 等都能直连；其他 OpenAI 兼容端点也可以手填。

点「测试连接」确认

它会真实跑一次翻译，确认 Key、网关与模型三件事都对，再开始用。

注意额度

翻译消耗你自己的 API 额度。同时启用多个服务时，一次翻译会同时用掉这几个服务的额度。

已知限制

只在 Windows 上构建与验证过。macOS 和 Linux 尚未实现，界面上只会提示当前平台不支持。

截图识别用内置的 PaddleOCR（PP-OCRv4 中英文模型）在本机完成，首次使用不需要联网。手写体、竖排文字与极小字号仍会出错。

朗读用系统自带语音，音色与效果取决于系统装了哪些语音包。

插件不能联网，只能读写剪贴板，且需要先申请权限。

API Key 只写进 Windows 凭据管理器，配置文件里零明文。

从源码构建

需要 Node 18 以上、pnpm，以及 Rust stable 的 MSVC 工具链。

pnpm install
pnpm tauri dev      # 开发调试
pnpm tauri build    # 打包安装程序

打 v* 标签会自动触发 .github/workflows/release.yml， 在 GitHub 的 Windows 机器上构建并发布。
