设计说明

  • 界面文案、按钮名称与控件集合与当前实现保持一致，未增删功能。
  • 图标统一为 16px 线性 SVG，颜色跟随文字，不使用图标字体或外部文件。
  • §9 交互流程按当前实现整理：划词 = 热键 → 借用剪贴板取词 → 光标旁弹窗并发；截图 = 热键 → 全屏冻结框选 → 本地 PaddleOCR → 结果窗。取词与框选都可随时 Esc 退出。
  • 文字对比度按 WCAG 2.1 计算，正文不低于 4.5:1，数值见附录 B。
  • 颜色分四类：品牌色用于识别，交互色用于可点击元素，语义色用于状态，中性色用于文字与分隔。
  • 里程碑状态使用中性标签，运行时状态使用圆点与语义色，两者不共用同一视觉。
  • 危险操作保留二次确认；写回类操作保留撤销与降级为复制的路径。
  • 结果面板只保留原文与译文列表，不再有互斥模式（v0.9.1 起原图覆盖已移除，见末尾两条）。
  • 深色区域仅用于截图场景，token 见附录 B。
  • 配色、字阶与毛玻璃参数已同步到 src/styles/tokens.css，本稿与实现一一对应。
  • 底色使用多层径向渐变叠加并缓慢位移，任何时候都不是一块纯色；卡片与按钮用 backdrop-filter 做毛玻璃。
  • 窗口宽度在 900–2560 之间时，设置页主内容区封顶 980px 并居中，两侧留白随窗口变化。
  • 品牌蓝只有当文字用时才换 --c-primary-text：#3964FE 作文字在应用底上只有 4.38:1，达不到 4.5:1。按钮底仍然是 #3964FE 配白字。
  • 热键冲突态给出替代组合与「采用建议」；「恢复默认热键」只在确实改过键时出现，没改过就不摆一个按不动的按钮。
  • 截图框选不画四角把手：松开即提交、不能二次调整，画出可拖拽的把手会承诺做不到的事。
  • 截图识别的结果面板给原文与各服务译文；原图覆盖 v0.9.1 已移除（第 3 节覆盖区保留为历史记录）。译文行数与原文对不上时的整块铺放方案随覆盖一并移除。
  • 截图识别暂不做 AI 视觉兜底：把选区图片发给模型需要多模态调用，而 DeepSeek 这类纯文本模型不支持，得先按服务能力区分。没实现就不摆这个开关。
  • 输入框转译的撤销交给目标程序自己的 Ctrl+Z，不弹 8 秒撤销条：那 8 秒里用户可能已经改过内容，再写回一次比让用户自己撤销更容易出错。写回前的焦点快照校验与失败降级为复制照做。
  • 组件小字在实现里落在 6 级字阶的 11px 与 12px 两档；稿中个别 11.5px 是早期写法，以实现为准。
  • 品牌标记与应用图标、favicon 是同一枚（气泡 + 译 + 星芒 + AI 徽章，底层淡靛留出纸叠的缝）：页内用内联 SVG，本稿仍然零外部依赖。矢量源文件 design/brand/logo.svg 当前仓库未包含，位图以 src-tauri/icons 为准。
  • 添加服务先挑提供商：预设给的是地址、推荐模型与密钥页链接，逐条标注官方文档来源与核对日期；模型始终可手填，也能用「测试连接」从服务端 /models 拉回候选。百炼的地址含工作空间 ID、火山方舟要填接入点 ID，这两家只给占位与提示，不猜值。
  • 本地服务（Ollama 这类）显式标成「不需要密钥」，请求不带 Authorization 头，而不是发一个空的 Bearer。
  • 服务端报错换成人话：401 密钥无效、402 余额不足、403 无该模型权限、404 地址或模型名不对、429 太频繁；每条配动作按钮（打开控制台、重新粘贴、改用某模型），原始 JSON 折叠在「详情」里，能抓到 Key 尾号就一并显示。
  • 关于页只放对用户有用的三件事：这是谁、数据存在哪、出问题怎么把线索带走。诊断区给路径与日志，快捷键速查显示当前生效组合（未注册的标出来）。许可为 MIT，写在仓库层而不是界面层。
  • 模型选择是自定义下拉而不是原生 datalist：原生控件样式跟系统走、且不能分组；这里要能显示「服务端返回 / 预设推荐」两组、要能键盘操作、还要留「刷新模型」。选中已配 Key 的服务时后台自动拉一次，失败只在面板底部显示原因，不弹 toast 打扰。
  • v0.8.1 起「输入框转译（Alt+T）」已从产品里移除：全局热键去改用户编辑器里的内容，焦点认错与剪贴板残留的代价大于收益。本稿第 2 节保留为历史记录，热键只剩划词与截图两条。
  • v0.8.1 起窗口 × 的选择是「直接关闭 / 收进托盘」，托盘图标常驻右下角，左键唤回窗口、右键菜单里有显示主窗口、检查更新与退出。
  • v0.9.0 起截图识别改用本机的 PaddleOCR（PP-OCRv4 中英文模型 + ONNX Runtime，随安装包分发）：中文与单行框选的识别质量明显好于 Windows 自带 OCR，模型缺失或加载失败时自动回落到系统 OCR。模型与运行时约 34MB，安装包因此从 3MB 涨到 20MB 左右。
  • 「测试连接」改成真实调用一次模型（同一个协议、同一个模型），不再只看 /models：模型列表对所有人可见，能不能用是另一回事，「测试通过但翻译 403」就是这么来的。代价是消耗几十个 token。
  • v0.9.1 起结果面板去掉「结果面板 / 原图覆盖」的二选一，只保留原文与译文列表：覆盖模式要在选区图上按行贴译文，实际用起来辨识成本高于收益，而且那张选区图的 base64 有数 MB 常驻在事件负载里。本稿第 3 节的覆盖区保留为历史记录。
  • v0.9.2 起更新下载是窗口级的一件事：状态放模块级而不是关于页的组件里，切页、关掉设置页都不中断；Rust 侧只允许一个下载在跑，取消后立刻收尾并删掉半截文件。进度在同一次下载内只增不减，断线重试停在当前高水位并标注重试次数。下载完成时若不在关于页就只提示，不自动退出应用。
  • v0.8 对齐：主窗口未关 decorations，标题栏由系统绘制，稿内按 Win11 风格复现（左侧应用名、右侧最小化/最大化/关闭，关闭悬停转红）；没有自绘窗口控制钮。
  • v0.8 对齐：窗口参数——主窗口 1024×700（最小 900×620）、划词弹窗 430×540（Acrylic r14、可拖动）、截图框选全屏覆盖、OCR 窗 460×600（最小 380×360、Acrylic r14）、轻提示 420×66（Acrylic r10、不可聚焦、鼠标穿透）。
  • v0.8 对齐：通用、热键、服务配置、历史记录、生词本、语音合成、插件、关于全部是主窗口「设置」页签里的侧栏页，没有独立窗口；侧栏宽 186px、玻璃底，主内容区透明底、980px 封顶。
  • v0.8 对齐：全局热键只有划词 Alt+D 与截图 Alt+S 两条，状态签为「已启用 / 已被占用」；占用横条与建议组合在热键页内，不在独立弹层。
  • v0.8 对齐：关于页没有「退出随译」按钮（退出在托盘菜单）；链接区第四项是「获取更新 · 当前版本」；OCR 窗内的隐私提示（识别在本机完成、截图不上传）是面板一部分，不是页面底栏。
