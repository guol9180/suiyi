实现要点（对应 M0–M3 里程碑）

  • 流式输出：SSE 增量渲染，多个结果卡独立推进，完成态显示耗时
  • 多服务编排：拖拽排序、并发对比、失败自动沿回退链切换
  • 写回安全：替换前对选区/输入框做快照校验，焦点变化即回退为复制+通知
  • 密钥安全：API Key 只存 Windows 凭据管理器 / macOS 钥匙串，配置文件零明文
  • 原图翻译：OCR 返回行级坐标，译文按坐标覆盖渲染，支持整体开关
  • 配置即服务：所有翻译/OCR/语音服务统一 Schema，插件注册的服务与内置同权
